# Hanko

判子 · a configurable bar for [Omarchy](https://github.com/omacom/omarchy), printed in your theme's paper and ink.

**Status: gama1, design only.** gama1 merges the beta1 and alpha1 directions into one bar where every part is a setting: 15 settings, 6 presets, 2,985,984 combinations. There is no plugin code yet; the plugin (`hanko.bar`, a full-bar Omarchy plugin) comes next.
