# Hanko 判子, the Omarchy theme

One paper, warm ink, one vermilion seal: the theme the hanko.bar plugin is drawn in.

```sh
hanko theme install        # links this folder as ~/.config/omarchy/themes/hanko
omarchy theme set hanko
```

Omarchy's templates make the terminal configs from `colors.toml`. This folder adds btop (`btop.theme`, written by `lua assets/kaze/btop.lua theme/colors.toml`) and Neovim (`neovim.lua`, which loads the plugin's `assets/kaze/nvim/colors/hanko.lua`).

## The prints

Re-encoded at 2560 px. With Kaze on, `hanko.background` prints each one again in the theme's inks. The works are old enough to be in the public domain:

- `1-pines-night.jpg`, `4-pines-left.jpg`, `5-pines.jpg`: after Hasegawa Tōhaku, *Pine Trees* (Shōrin-zu byōbu), 16th century
- `2-great-wave.jpg`: Katsushika Hokusai, *The Great Wave off Kanagawa*, c. 1831
- `3-red-fuji.jpg`: Katsushika Hokusai, *Fine Wind, Clear Morning*, c. 1831
- `6-sudden-shower.jpg`: Utagawa Hiroshige, *Sudden Shower over Shin-Ōhashi Bridge and Atake*, 1857
- `7-haboku.jpg`: Sesshū Tōyō, *Haboku Landscape*, 1495
